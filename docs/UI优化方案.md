# 有数 · UI 优化方案（定稿 v1.0）

> 来源：2026-10-10 ~ 10-11 三轮原型评审（`prototype/proposals.html` v1/v2），用户逐条拍板后汇总。
> 基线代码：`prototype/v4.html` + `prototype/shared.js`（含 2026-10-10 晚用户侧改动：单行工具栏、统计页 4 格总览、双 TOP5、分类分布去切换、损耗排行移除）。
> 本文档是编码实现的**唯一依据**，实现完成后同步更新 `AGENTS.md`。

## 二、首页：资产卡

**位置**：`scr-list` 内容区最顶部（搜索工具行之上）。

**结构**（shared.js 新增 `renderAsset()` 输出，v4 写样式）：
- 深色渐变卡（`linear-gradient(135deg,#171717,#2C2C2C)`，圆角 20px，投影），与「我的」页 hero 同质感语言
- 上行：小标签「总价值 · 原价」（letter-spacing 宽排）+ 大数字 **¥25,108**——字体同 `.hero .big`（`-apple-system` 系、`font-weight:800`、`letter-spacing:-1.5px`），**不用 Georgia 衬线**
- 下行：细分隔线 + 三格：`在册 N 件` / `日均总成本 ¥x` / `已归档 N 件`

**数据口径**：与统计页一致，只计未归档；已归档件数单列。

## 三、详情页：回本视角 + 日均曲线 + 编辑入口

整体 5 区块（顺序固定）：**大数字 hero → 回本进度卡 → 日均走势曲线卡 → 字段卡 → 操作按钮**。

1. **回本进度卡**（原「损耗率」卡改造）：
   - 标题改「回本进度（时间维度）」，百分比与进度条阈值配色不变
   - 底部新增目标行：未回本 → `🎯 再用 N 天回本 —— 之后每天都是纯赚`；已回本（损耗=100%）→ `✅ 已回本，之后每天都是纯赚`
   - 归档物品按归档日冻结计算（`refDate` 现有逻辑天然支持）
2. **日均价格走势曲线卡**（新增，shared.js 生成 SVG）：
   - 横轴 = 持有天数（最小单位：天），纵轴 = 日均价格
   - 实线 = 已发生（自满月第 30 天起）；虚线 = 预测至回本日；目标日均 = 灰色横虚线 + 标签；「今天」= 黑点 + 数值
   - 前 30 天日均过高，自满月起展示（卡片底部小字说明）；**持有不足 30 天则从第 1 天起、不显示截断说明**
   - 归档物品：实线画到归档日，**不画预测虚线**，结论改为已冻结提示
   - 底部一句结论：`当前日均比目标高 x.x%，再用 N 天追平目标`（≤目标时：`已优于目标 x.x%`）
3. **编辑入口**：详情页 navbar 右侧「编辑」文字按钮 → 进入编辑页。

## 四、编辑物品（复用录入表单）

- `openEdit(id)`：复用 `scr-entry` 表单，预填名称/价格/日期/品牌/分类/年限（年限命中快捷 chip 则高亮，否则填入自定义框）；navbar 标题改「编辑物品」，按钮改「保存修改」，顶部显示提示条「修改价格/日期/年限将重新计算量化指标」
- `saveEntry()` 增加编辑分支：有 `editId` → 原地更新该物品（保留 id、归档状态、`archivedAt`；emoji 随分类联动），保存后返回详情页；无 → 维持新增逻辑
- 归档物品同样可编辑

## 五、统计页：重构

现有结构（用户 2026-10-10 晚刚改）：4 格总览 → 分类分布（双指标行、无切换）→ 日均最贵 TOP5 → 持有最久 TOP5 → 归档。

**定稿结构**（自上而下）：

1. **4 格总览**：总资产 / 总日均 / 件数 / 平均持有——**保持现状不动**
2. **月结条**（新增小卡）：`📅 本月（YYYY-MM）　新增 X 件 · 归档 Y 件`
3. **分类分布**：**保持现状不动**（维持用户刚定的双指标行、无切换）
4. **排行榜**（合一卡，替换现有两个 TOP5 卡）：标题 + iOS 风分段切换（`.seg`），4 个榜：
   - `日均最贵`（吸收现有 TOP5，黑条）
   - `日均最值`（新增：日均最低 Top5，绿条 #07C160）
   - `持有最久`（吸收现有 TOP5，黑条，右侧 `N 天`）
   - `品牌`（新增：按品牌聚合总价 Top5，右侧 `¥x · N 件`）
5. **累计总资产**（新增卡）：标题右侧小分段切换 `月度 / 年度`（默认月度），SVG 折线：在册物品原价累计总和，不含归档；年度模式每个点画圆点，月末/年末标签自适应
6. **归档物品**：保持现状不动

## 六、工程约束

- `shared.js` 是四版共享逻辑层：本次新增的结构（资产卡 / 曲线卡 / 排行榜 seg / 累计资产 SVG）在 **v4 写完整样式**；`index/v2/v3` 三个参考版**补最小兼容样式**（防止裸奔，不追求精致），不再投入设计
- `shared.js` 新增工具函数：`fmt0`（整数千分位）、`dailyChartSVG(it)`、`cumAssetSVG(unit)`、`renderAsset()`、`renderRank(mode)`、`renderCum(unit)`、`openEdit(id)`
- 铁律不变：禁止横向滚动（分段切换器 4 项等分平铺，不滚动）；损耗阈值配色不变；分类单一数据源不变
- 验证：`node --check shared.js` + 浏览器打开 v4.html 逐屏走查（列表/详情/编辑/统计/归档/我的）

## 七、明确不做（本轮边界）

- 列表排序（用户放弃）
- 「剩余未摊销」及任何估值类概念（用户否决）
- 「每年新增投入」柱状图（用户砍掉）
- 实物照片、社交分享（维持 v1 边界，照片留作 v2 第一候选）
