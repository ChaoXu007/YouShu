## 一、已确认的产品决策（基线 + 细化）

### 基线（4 条）
| 维度 | 决策 |
|---|---|
| 录入方式 | 聚焦**手工录入**，界面极简、操作流畅、步骤最少化（当前阶段核心体验） |
| 数据同步 | **v1 暂不做**云端同步与订阅（保持简单）；本期仅本地存储 + 导出/导入。云端同步 + 50 条免费额度 + ¥1/月订阅作为**可配置项预留至 v1 之后** |
| 功能边界 | **不做** AI、录音、拍照/条码识别等复杂功能，保持轻量 |
| 规避项 | 不做广告变现；严防录入摩擦、单平台、UI 粗糙、技术细节翻车、耐用品/消耗品混算 |

### 细化决策（6 项，已拍板）
1. **目标人群**：面向更广的"收纳控 + 普通消费者"（不限于数码/家电爱好者）。
2. **统计页进 MVP**：物品 / 统计 / 我的 三个 Tab 均在首版实现。
3. **损耗率**：默认时间维度；录入时**引导填预计使用年限**，提供快捷选项（半年 / 1年 / 2年 / 3年 / 5年 / 自定义）。
4. **免费额度 50 条、订阅价 ¥1/月**，**两者均可在后台配置**。
5. **slogan**：「你的物品，心里有数。」
6. **导出格式**：JSON（导入同步支持）。

## 二、产品定位

### 2.1 目标人群
- **核心**：注重"消费清醒 / 物品掌控感"的城市人群——收纳控、普通消费者、精打细算的生活管理者。
- **典型画像**：买完东西想算"值不值"；换季/搬家整理时盘点家底；冲动消费前想冷静一下。

### 2.2 核心场景
1. **买后复盘**：录入新买物品，立刻看到"日均成本"。
2. **整理盘点**：换季/搬家清点，看清总资产与损耗分布。
3. **消费冷静**：再买同款前，看旧物"持有天数 + 日均成本"做决策。

### 2.3 产品名称与 slogan
- **产品名**：**有数**
- **slogan**：**你的物品，心里有数。**

### 2.4 一句话定位
一款**微信小程序**形态的个人物品账本「有数」：极简录入，自动算出每件物品的**日均使用价格与损耗率**，帮你用数据掌控拥有。

**差异化锚点**：微信小程序（免安装/跨平台/易分享）+ 免费无广告 + 聚焦"持有成本量化"（竞品多为 iOS-only 且偏重功能）。

## 三、核心量化指标模型（产品灵魂）

### 3.1 平均使用价格（日均成本）
```
日均成本 = 购入价 / 已持有天数
已持有天数 = 今天 − 购买日期
```
- 示例（原型数据）：iPhone 15 Pro 8799 元，持有约 1026 天 → 日均 ≈ ¥8.58。

### 3.2 预期日均成本（成就暗示）
```
预期日均 = 购入价 / (预计使用年限 × 365)
```

### 3.3 当前损耗率（时间维度，默认）
```
时间损耗率 = 已持有天数 / (预计使用年限 × 365) × 100%
```
- 录入时引导填"预计使用年限"（快捷选项：半年 / 1年 / 2年 / 3年 / 5年 / 自定义）。
- 价值维度（需填当前估值）作为后续增强，本期不做。

### 3.4 持有进度 / 剩余寿命
```
剩余天数 = (预计使用年限 × 365) − 已持有天数
```
- 用**时间进度条**可视化，首屏强记忆点。

## 四、单物品数据模型（字段）

| 字段 | 必填 | 说明 | 解锁能力 |
|---|---|---|---|
| 名称 name | ✅ | 物品名 | 基础 |
| 购买价格 price | ✅ | 金额 | 日均成本 |
| 购买日期 date | ✅ | 日期 | 日均成本/持有天数 |
| 预计使用年限 life | ✅(引导) | 年（含快捷选项） | 损耗率/进度条/预期日均 |
| 分类 category | △ | 预设+自定义 | 统计/筛选 |
| 品牌 brand | ❌ | 文本 | 展示 |
| 归档 archived | ❌ | 布尔；归档后首页隐藏、不计入统计；可"恢复"或"彻底删除" | 首页/统计过滤 |
| 当前估值 / 额外费用 | ❌ | 后续增强 | 价值损耗率 / 真实投入 |

> 取消"状态"字段（服役中/闲置/已转让/已报废），改用"归档"概念：归档=隐藏+退出统计（数据保留）；删除=彻底删除（不可恢复，带二次确认）。
> 本期**不做**拍照/条码：图标用分类 emoji。

## 五、功能规划（MVP 范围）

### P0（MVP 上线）
- [ ] **极简手工录入**：名称/价格/日期 3 必填 + 引导填预计年限（快捷选项）+ 展开更多（品牌/分类）；支持"先存后补"。
- [ ] **物品列表 / 详情**：列表含 emoji、名称/品牌、日均成本小标、迷你损耗进度条；详情大数字 + 进度条 + 字段；支持**归档**（隐藏+退出统计）与**删除**（彻底删除，二次确认）。
- [ ] **核心计算与展示**：日均成本、持有天数、损耗率（时间维度）、进度条。
- [ ] **分类管理**：预设分类（数码/家电/服饰/美妆/图书/其他），**每个分类配套 emoji 图标**，录入时以图标芯片选择。
- [ ] **导出 / 导入**：本地备份与跨设备迁移（客户界面仅称"导出数据/导入数据"，不暴露 JSON 技术细节；实际格式 JSON，含归档数据）。
- [ ] **统计页（进 MVP）**：总资产、总日均成本、分类分布（环形图）、损耗排行（Top 5）；独立「归档物品」模块（数量 + 分类标签，点击进入归档列表）。
- [ ] **"我的"页（v1 极简）**：产品名「有数」+ slogan「你的物品，心里有数。」、导出数据、导入数据、关于。

### 归档 vs 删除（明确区分）
- **归档**：物品从首页与统计中移除（不计入资产/成本/排行），但数据保留；可在「归档物品」页**恢复**或**彻底删除**。
- **删除**：彻底删除数据，不可恢复，操作带二次确认。

### v1 明确延后（预留可配置，后续版本）
- ⏸ **云端同步 + 免费 50 条额度**（可配置）：超出引导订阅（¥1/月，可配置）。
- ⏸ **升级订阅入口**。

### P1（迭代增强）
- [ ] 额外费用记录与累加（真实累计投入）。
- [ ] 价值维度损耗率（当前估值）。
- [ ] 搜索 / 筛选 / 排序增强（按品类、损耗率、持有时长）。
- [ ] 预计年限模板（按品类推荐默认值）。
- [ ] 批量归档 / 批量恢复。

### 明确不做（本期）
- ❌ AI 自动识别、录音、拍照/条码扫描。
- ❌ 社交分享、社区、排行榜。
- ❌ 广告变现。
- ❌ 多人协作 / 家庭共享。
- ❌ 估值字段（本期不做价值维度损耗率）。

## 六、信息架构（IA）

### 底部 Tab（3 个，均在 MVP）
1. **物品**：搜索 + 分类筛选 + 列表（迷你进度条，仅未归档）+ 新增（➕）。
2. **统计**：总资产、总日均、分类分布、损耗排行 + 独立「归档物品」模块（点击进入归档列表）。
3. **我的**：产品名+ slogan、导出数据、导入数据、关于（v1 不含云端同步与订阅）。

### 核心流程
```
[物品列表] ──➕──> [极简录入] ──> [物品详情(大数字+进度条)]
[物品列表] ──点击──> [物品详情] ──归档 / 删除(二次确认)
[统计] ──归档模块──> [归档物品页] ──恢复 / 彻底删除
[我的] 为独立 Tab
```

## 七、UI 设计方案（已出高保真原型）

- **风格**：极简 + 留白 + 卡片化，主色微信绿 #07C160（传达"清醒/掌控"），进度条为记忆点。
- **损耗进度条配色（按阈值）**：<50% 绿 `#07C160` / 50%~80% 黄 `#F2C037` / 80%~100% 红 `#EF4B4B`——"损耗"为负面信号，用红黄绿梯度表达紧迫度，而非全程绿色。
- **首屏**：单个物品突出大数字（日均成本 + 持有天数），而非一上来堆图表。
- **录入**：3 必填 + 年限快捷选项（默认 1 年、可改/自定义）+ 实时"日均预览"；分类以**图标芯片**选择；先存后补。
- **"我的"页**：顶部展示产品名「有数」与 slogan「你的物品，心里有数。」；菜单仅"导出数据 / 导入数据 / 关于"，不暴露 JSON 与订阅/同步（v1 不做）。
- **归档 / 删除**：详情页区分"归档"（隐藏+退出统计）与"删除"（彻底删除，二次确认）；统计页独立"归档物品"模块，点击进入归档列表可恢复/彻底删除。
- **高保真原型**：`prototype/index.html`（可点击交互：切 Tab、加物品、选分类图标、详情、归档/删除、统计、归档模块、导出备份）。
